# 세션 시작 절차 (EFB 브리핑 웹앱)

이전 대화를 기억에 의존하지 않는다. 프로젝트 문서와 실제 코드로 상태를 파악한다.

1. `CLAUDE.md` 규칙을 따른다 (이미 로드됨).
2. `docs/CURRENT_STATUS.md` 전체를 읽는다 — 상태표, "다음에 할 작업", 맨 아래 "세션 인계".
3. 사용자가 이번 작업을 말했으면 그 작업, 아니면 CURRENT_STATUS의 "다음에 할 작업" 1번을 후보로 제시한다.
4. 이번 작업과 **관련된 절만** 읽는다:
   - 요구사항 → `docs/PROJECT_SPEC.md` 해당 절
   - 파일·흐름 → `docs/ARCHITECTURE.md` 해당 절
   - 결정 → `docs/DECISIONS.md`에서 관련 D-번호 (검색해서 해당 항목만)
   - 문제 → `docs/KNOWN_ISSUES.md` 관련 항목
5. 관련 소스 파일만 직접 확인한다. 프로젝트 전체·모든 문서를 읽지 않는다.
6. 문서와 코드가 다르면 코드가 기준 — 사용자에게 차이를 알린다.
7. 시작 전에 사용자에게 한국어로 짧게 보고한다:
   - 현재 상태 한두 줄 (Phase, 마지막 검증 결과, 미확인 항목)
   - 이번 작업 계획 (단계)
   - 확정 결정과 충돌하거나 사용자가 정해야 할 것이 있으면 질문
8. 사용자가 동의하면 작업을 시작한다. 큰 작업은 기능 단위로 나눈다.
